# WM_CHECKLIST

Адаптивный веб-чеклист и трекер покупок для ПК и мобильных устройств на чистом HTML/CSS/JS без серверной части и сборщиков.

**Демо (GitHub Pages):** https://whtmst.github.io/checklist/

> **Приватность:** в этом репозитории лежит только чистый интерфейс. Все записи хранятся локально в `localStorage` вашего браузера, а при желании синхронизируются с **вашим собственным** скрытым GitHub Gist. Пользователи полностью изолированы друг от друга.

## Возможности

- **Несколько вкладок-списков** — создавайте отдельные списки (например, «Основная», «Курьер», «Дом») с независимым подсчётом итогов, а также **переносите или копируйте** категории и отдельные карточки между вкладками.
- **Категории и компактные карточки** — 5 уровней приоритета (`КРИТИЧНО`, `ОЧЕНЬ ВАЖНО`, `СРЕДНЕ`, `ЖЕЛАТЕЛЬНО`, `МОЖНО ОБОЙТИСЬ`), выбор источника (`Местный рынок`, `Birmarket`, `Temu`, `Ozon` или свой вариант), кликабельный бейдж магазина (`↗`), поиск и фильтры.
- **Выдвижная панель просмотра карточки** — справа на ПК и шторкой снизу на мобильных устройствах. Строки в заметке формата `Ключ: Значение` автоматически раскладываются в опрятную таблицу характеристик.
- **Учёт кредитов и рассрочек** — поддержка как индивидуальных кредитов на один товар, так и **общих кредитов** (объединение нескольких товаров в один кредит без двойного счёта в итогах). Ежемесячный платёж и итоговая сумма вводятся вручную под реальный график банка; по дате оформления и сроку автоматически считаются дата окончания, количество оставшихся платежей, остаток суммы и прогресс выплаты.
- **Итоговая сводка по вкладке** — 3 отдельных показателя: потрачено (с разбивкой наличные / кредит), ежемесячная нагрузка по активным кредитам и всего запланировано.
- **Светлая и тёмная темы** — тёмная тема по умолчанию, все цвета вынесены в CSS-переменные `:root` в `css/tokens.css`.
- **Локальный бэкап** — экспорт/импорт резервной копии в `.json` и копирование в буфер обмена.

## Как работает синхронизация (Secret GitHub Gist)

Синхронизация между ПК и телефоном работает напрямую через GitHub API без промежуточных серверов:

1. **Автоотправка (Auto-Push):** после любого изменения (галочка, правка, удаление, перенос) данные мгновенно сохраняются локально, а через **1.5 секунды** после последнего действия отправляются в скрытый Gist (`wm-checklist-data.json`).
2. **Бережная автоподгрузка (Auto-Pull):** при открытии страницы, возврате на вкладку (разблокировке телефона) и раз в **60 секунд** (только пока вкладка активна на экране) приложение проверяет обновления с заголовком `ETag` (`If-None-Match`). Если изменений нет, GitHub отвечает `304 Not Modified` и **не расходует лимит GitHub API** (0 из 5 000 запросов в час).
3. **Защита от перезаписи:** локальное состояние обновляется только если версия в Gist новее (`updatedAt`), а при необходимости можно принудительно обновить данные кнопкой с индикатором в шапке.

## Настройка синхронизации на своих устройствах

1. На GitHub откройте **Settings → Developer settings → Personal access tokens → Tokens (classic)** → **Generate new token (classic)**.
2. Укажите название (например, `wm-checklist`), срок действия и отметьте **только одно право — `gist`**.
3. Скопируйте полученный токен (`ghp_...`).
4. **На первом устройстве (ПК):** откройте https://whtmst.github.io/checklist/, нажмите **Настройки**, вставьте токен → **Сохранить настройки** → **Отправить в GitHub ↑** (создастся скрытый Gist, его `Gist ID` пропишется автоматически).
5. **На втором устройстве (телефон):** откройте ту же ссылку, зайдите в **Настройки**, вставьте тот же токен → **Найти мой Gist** → **Загрузить с GitHub ↓**.

> Токен сохраняется только в `localStorage` вашего браузера и никогда не попадает в код репозитория. При перевыпуске (Regenerate) токена данные в Gist не теряются — достаточно вставить новый токен в настройках.

## Структура проекта

```text
index.html        — разметка страницы, выдвижной панели и модальных окон
css/
  tokens.css      — все цветовые переменные (:root) для тёмной и светлой тем
  styles.css      — адаптивная верстка для ПК и мобильных устройств
js/
  config.js       — справочники (приоритеты, магазины, валюта) и расчёт графика кредита
  storage.js      — работа с localStorage, CRUD, перенос между вкладками и подсчёт итогов
  sync.js         — синхронизация через Secret GitHub Gist (ETag / Auto-Pull) и JSON-бэкапы
  render.js       — безопасная DOM-отрисовка списка, карточек, бейджей и панели просмотра
  app.js          — обработчики событий, модалки, фильтры, переключение темы
```

## Запуск собственной копии на GitHub Pages

1. Сделайте форк или скопируйте файлы в корень своего репозитория.
2. Включите публикацию в **Settings → Pages → Build and deployment**:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` / `/ (root)` → **Save**.
3. Через 1–2 минуты приложение станет доступно по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
