# WM_CHECKLIST

Адаптивный офлайн-чеклист и трекер покупок (PWA) для ПК и мобильных устройств на чистом HTML/CSS/JS без серверной части, сборщиков и внешних зависимостей.

**Демо (GitHub Pages):** https://whtmst.github.io/checklist/

> **Приватность:** в этом репозитории лежит только чистый интерфейс. Все записи хранятся локально в `localStorage` вашего браузера, а при желании синхронизируются с **вашим собственным** скрытым GitHub Gist. Пользователи полностью изолированы друг от друга.

## Возможности

- **PWA и полноценный офлайн-режим** — приложение можно установить на домашний экран телефона или ПК (как нативное приложение без браузерной строки). Все файлы и локальный шрифт кэшируются Service Worker (`sw.js`), поэтому можно просматривать, добавлять, редактировать и отмечать покупки полностью без интернета.
- **Несколько вкладок-списков и управление ими** — отдельные списки (например, «Основная», «Курьер», «Дом», «Архив 2026») с независимым подсчётом итогов, плавной прокруткой вкладок (стрелки `‹`/`›`, перетаскивание мышкой и колёсико на ПК), переносом/копированием категорий и карточек между вкладками и менеджером вкладок (`•••` — сортировка `↑`/`↓` и drag-and-drop).
- **Категории, порядок и массовое сворачивание** — сворачивание любой категории кликом по всей её шапке, кнопка массового сворачивания/разворачивания (`−` / `+`) и менеджер категорий (`•••` — сортировка `↑`/`↓`, перетаскивание `⋮⋮`, переименование, перенос и удаление).
- **Компактные карточки, сортировка и фильтры** — 5 уровней приоритета (`КРИТИЧНО`, `ОЧЕНЬ ВАЖНО`, `СРЕДНЕ`, `ЖЕЛАТЕЛЬНО`, `МОЖНО ОБОЙТИСЬ`), выбор магазина (`Местный рынок`, `Birmarket`, `Temu`, `Ozon` или свой вариант), кликабельный бейдж-ссылка магазина (`↗`), 5 режимов сортировки (`По приоритету`, `Сначала дорогие`, `Сначала дешёвые`, `Сначала новые`, `По алфавиту`) и фильтры по статусу, приоритету и магазину.
- **Глобальный Spotlight-поиск (`🔍 Поиск` / `Ctrl + K`)** — умный многословный поиск сразу по всем вкладкам (включая архив), категориям, магазинам, названиям кредитов и всем строкам характеристик в заметках с подсветкой совпавшей строки, навигацией стрелками `↑`/`↓` + `Enter` и мгновенным переходом к карточке.
- **Выдвижная панель карточки + фото-галерея** — открывается справа на ПК и шторкой снизу на мобилке. Поддерживает до 3 фото товара по URL (динамическое добавление полей `1 → 2 → 3`, галерея со стрелками/точками, полноэкранный зум Lightbox и тихое скрытие битых ссылок), а строки в заметке формата `Ключ: Значение` автоматически раскладываются в аккуратную таблицу характеристик.
- **Удобный ввод без потерь** — создание новой категории прямо из окна позиции (`+ Новая категория...`), автосохранение черновика, кнопка «Очистить», защита от случайного закрытия несохранённой формы и авторасширение поля заметки под текст.
- **Единый учёт кредитов, рассрочек и карты (кнопка «Кредиты» в шапке):**
  - 4 типа оплаты в долг: **`Рассрочка`** (0%), **`Ninja`** (разделение с %), **`Льготный период`** (с датой «Оплатить до» и счётчиком оставшихся дней) и **`Свой вариант`**.
  - Оформление как на 1 товар, так и на **пачку товаров из разных вкладок** (в итоги каждой вкладки идёт её честная пропорциональная доля без двойного счёта). В окне выбора товаров уже оформленные в другие кредиты позиции скрыты по умолчанию, есть поиск и сворачивание вкладок.
  - Ручной ввод реального ежемесячного платежа и итоговой суммы под график банка; автоматический расчёт переплаты, даты окончания, оставшихся платежей и полоски прогресса.
  - Справочные поля **«Лимит карты»** (занято / свободно) и **«Доход / мес»** (процент кредитной нагрузки и остаток после платежей).
- **Светлая и тёмная темы + локальный шрифт** — тёмная тема по умолчанию, все цвета вынесены в `:root` в `css/tokens.css`, однострочная компактная шапка с иконками на мобильных экранах и локальный вариативный шрифт **Finlandica** (работает 100% офлайн).
- **Локальный бэкап** — экспорт/импорт резервной копии в `.json`, копирование в буфер обмена и полная очистка данных.

## Как работает синхронизация и офлайн-автослияние (Secret GitHub Gist)

Синхронизация между ПК и телефоном работает напрямую через GitHub API без промежуточных серверов:

1. **Автоотправка (Auto-Push):** после любого изменения данные мгновенно сохраняются локально, а через **1.5 секунды** после последнего действия отправляются в скрытый Gist (`wm-checklist-data.json`).
2. **Бережная автоподгрузка (Auto-Pull):** при открытии страницы, возврате на вкладку (разблокировке телефона) и раз в **60 секунд** (только пока вкладка активна на экране) приложение проверяет обновления с заголовком `ETag` (`If-None-Match`). Если изменений нет, GitHub отвечает `304 Not Modified` и **не расходует лимит GitHub API** (0 из 5 000 запросов в час).
3. **Умное офлайн-автослияние (Auto-Merge):** у каждой вкладки, категории, позиции и кредита хранится собственная метка `updatedAt` (плюс реестр удалённых ID). Если вы вносили правки на телефоне без интернета и одновременно добавляли товары на ПК, то при появлении сети приложение **автоматически объединит изменения с обоих устройств без потерь** и отправит объединённую версию в Gist.

## Настройка синхронизации на своих устройствах

1. На GitHub откройте **Settings → Developer settings → Personal access tokens → Tokens (classic)** → **Generate new token (classic)**.
2. Укажите название (например, `wm-checklist`), срок действия и отметьте **только одно право — `gist`**.
3. Скопируйте полученный токен (`ghp_...`).
4. **На первом устройстве (ПК):** откройте https://whtmst.github.io/checklist/, нажмите **Настройки**, вставьте токен → **Сохранить настройки** → **Отправить в GitHub ↑** (создастся скрытый Gist, его `Gist ID` пропишется автоматически).
5. **На втором устройстве (телефон):** откройте ту же ссылку, зайдите в **Настройки**, вставьте тот же токен → **Найти мой Gist** → **Загрузить с GitHub ↓**.

> Токен сохраняется только в `localStorage` вашего браузера и никогда не попадает в код репозитория. При перевыпуске (Regenerate) токена данные в Gist не теряются — достаточно вставить новый токен в настройках.

## Структура проекта

```text
index.html        — разметка страницы, Spotlight-поиска, выдвижной панели, менеджеров и модальных окон
manifest.json     — манифест PWA для установки на телефон и ПК
sw.js             — Service Worker для кэширования и работы офлайн
assets/
  fonts/
    Finlandica-VariableFont_wght.ttf — локальный вариативный шрифт интерфейса
  icons/
    icon-192.png, icon-512.png       — иконки PWA
css/
  tokens.css      — подключение шрифта и цветовые переменные (:root) для тёмной и светлой тем
  styles.css      — адаптивная вёрстка, галерея, Lightbox, Spotlight и кастомные скроллбары
js/
  config.js       — справочники (приоритеты, магазины, типы долга) и расчёт сроков
  storage.js      — localStorage, CRUD, сортировка, перенос, единый реестр кредитов и поэлементный Auto-Merge
  sync.js         — синхронизация через Secret GitHub Gist (ETag / Auto-Pull / офлайн-очередь) и JSON-бэкапы
  render.js       — безопасная DOM-отрисовка списка, карточек, Spotlight, панели просмотра и сводки кредитов
  app.js          — события, drag-and-drop, прокрутка вкладок, галерея/Lightbox, черновики, фильтры, тема и PWA
```

## Запуск собственной копии на GitHub Pages

1. Сделайте форк или скопируйте файлы в корень своего репозитория.
2. Включите публикацию в **Settings → Pages → Build and deployment**:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` / `/ (root)` → **Save**.
3. Через 1–2 минуты приложение станет доступно по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
