# WM_CHECKLIST

Адаптивный офлайн-чек-лист, трекер покупок и учёт рассрочек/кредитов (**PWA**) для ПК и смартфонов на чистом **HTML / CSS / JS** — без сервера, сборщиков, рекламы и внешних трекеров.

**Демо (GitHub Pages):** https://whtmst.github.io/checklist/

> **Приватность:** в репозитории лежит только чистый интерфейс. Все ваши списки, цены, заметки и кредиты хранятся локально в `localStorage` вашего браузера, а при включении облачной синхронизации отправляются напрямую в ваш личный аккаунт выбранного сервиса.

## Возможности

- **Вкладки, категории и единый обзор «Все»**: группируйте покупки по проектам, переключайтесь на общий список всех позиций с глобальной сортировкой, фильтрами и сводкой без двойного учёта кредитов.
- **Кредиты, рассрочки (таксит 0%), Ninja и льготный период**: расчёт ежемесячной нагрузки, переплаты, лимита карты, графика платежей и точного остатка к выплате.
- **Быстрый поиск (Spotlight `Ctrl+K` / `/`)**: мгновенный поиск по всем вкладкам с чипами фильтрации (`Не куплено`, `Куплено`, `В кредите`, `Наличные`).
- **Мультиоблачная синхронизация (выбор одного активного провайдера)**:
  - **Локально** — только в браузере + ручной экспорт/импорт `.json` и умное напоминание о бэкапе (7 / 14 / 30 дней).
  - **GitHub Secret Gist** — до 10 МБ (`raw_url` fallback), фоновая проверка через `ETag 304`, фото по URL.
  - **GitLab Private Snippets** — до **50 МБ**, нативный CORS, фото по URL.
  - **Dropbox (App Folder)** — **2 ГБ бесплатно**, вход через OAuth 2.0 PKCE с постоянным `refresh_token`, плюс **прямая загрузка фото с устройства** (до 3 шт. на товар).
- **Безопасная загрузка фото (Dropbox + WebP)**: перед отправкой каждое изображение декодируется нативным декодером браузера, перерисовывается на чистый `<canvas>` (макс. `1280px`, сжатие в `WebP`) — это уменьшает размер в 5–15 раз, удаляет все EXIF/GPS-метаданные и обезвреживает файлы.
- **Офлайн-режим (PWA) и умное авто-слияние**: приложение работает без интернета, а при восстановлении связи аккуратно объединяет изменения с разных устройств без дублей.
- **3 языка интерфейса (`RU` / `EN` / `AZ`) и светлая/тёмная тема**: язык и тема хранятся локально на каждом устройстве независимо друг от друга.

## Подключение Dropbox (для владельца деплоя / форков)

Чтобы вход через **Dropbox** работал в один клик для всех пользователей:

1. Откройте [Dropbox App Console](https://www.dropbox.com/developers/apps) → **Create app** → **Scoped access** → **App folder** (назовите, например, `WM_CHECKLIST`).
2. Во вкладке **Permissions** отметьте:
   - `account_info.read`
   - `files.metadata.read`
   - `files.content.read`
   - `files.content.write`
   и нажмите **Submit**.
3. Во вкладке **Settings** добавьте ваш URL в **Redirect URIs** (например, `https://whtmst.github.io/checklist/`).
4. Скопируйте **App key** и вставьте его в `js/config.js` в поле `DROPBOX_APP_KEY` (либо пользователи могут вставить свой App Key прямо в настройках приложения).

## Структура проекта

```text
├── index.html          # Основное приложение (PWA)
├── privacy.html        # Политика конфиденциальности (для прямых ссылок / OAuth)
├── terms.html          # Условия использования
├── manifest.json       # PWA-манифест
├── sw.js               # Service Worker (офлайн-кэш)
├── css/
│   ├── tokens.css      # Палитра, шрифты и темы (dark / light)
│   └── styles.css      # Стили интерфейса
├── js/
│   ├── i18n.js         # Загрузчик локализаций (locales/*.json)
│   ├── config.js       # Конфигурация, расчёт кредитов и XSS-санитизация
│   ├── storage.js      # Локальное хранилище и алгоритм авто-слияния
│   ├── sync.js         # Мультипровайдерная синхронизация (GitHub / GitLab / Dropbox)
│   ├── photos.js       # Клиентское WebP-сжатие, очистка EXIF и кэш фото
│   ├── render.js       # Рендеринг интерфейса
│   └── app.js          # Логика приложения и обработчики событий
├── locales/
│   ├── ru.json         # Русская локализация
│   ├── en.json         # Английская локализация
│   └── az.json         # Азербайджанская локализация
└── assets/
    ├── fonts/          # Локальный шрифт Finlandica
    └── icons/          # Иконки PWA (192×192, 512×512)
```
