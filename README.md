# WM_CHECKLIST

Личный адаптивный чек-лист и трекер покупок с поддержкой вкладок, категорий, индивидуальных и общих кредитов/рассрочек, тёмной/светлой темы и синхронизацией через **Secret GitHub Gist**.

## Структура проекта

```text
index.html        — разметка страницы и модальных окон
css/
  tokens.css      — ВСЕ цветовые переменные (:root) для быстрой смены палитры
  styles.css      — адаптивная верстка под мобилку и ПК
js/
  config.js       — справочники (5 приоритетов, магазины, валюта)
  storage.js      — работа с localStorage, CRUD и расчёт итогов без двойного счёта
  sync.js         — синхронизация через GitHub Secret Gist API + JSON-бэкапы
  render.js       — отрисовка интерфейса
  app.js          — обработчики событий, модалки, тема
```

## 1. Запуск на GitHub Pages

1. Распакуй архив в корень репозитория `checklist` (`https://github.com/whtmst/checklist`).
2. Загрузи файлы в ветку `main` (через `git push` или через кнопку **Add file → Upload files** на GitHub).
3. Перейди в **Settings → Pages → Build and deployment**:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` / `/ (root)`
   - Нажми **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://whtmst.github.io/checklist/`.

## 2. Настройка синхронизации между ПК и телефоном (Secret GitHub Gist)

Чтобы никто чужой не видел и не мог изменить твой список, данные хранятся в скрытом Gist, а не в публичном репозитории:

1. На GitHub открой **Settings → Developer settings → Personal access tokens → Tokens (classic)**.
2. Нажми **Generate new token (classic)**.
3. Укажи название (например, `wm-checklist`), выбери срок действия и поставь **только одну галочку — `gist`**.
4. Скопируй сгенерированный токен (`ghp_...`).
5. **На ПК:** открой `https://whtmst.github.io/checklist/`, нажми **Настройки**, вставь токен, нажми **Сохранить настройки**, затем **Отправить в GitHub ↑** (создастся скрытый Gist и его ID заполнится сам).
6. **На телефоне:** открой ту же ссылку, нажми **Настройки**, вставь тот же токен, нажми **Найти мой Gist** → **Загрузить с GitHub ↓**.

Токен хранится только в `localStorage` твоего браузера и никуда не публикуется.
