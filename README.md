# WM_CHECKLIST

Адаптивный офлайн-чеклист и трекер покупок (PWA) для ПК и мобильных устройств на чистом HTML/CSS/JS без серверной части, сборщиков и внешних зависимостей.

**Демо (GitHub Pages):** https://whtmst.github.io/checklist/

> **Приватность:** в этом репозитории лежит только чистый интерфейс. Все записи хранятся локально в `localStorage` вашего браузера, а при желании синхронизируются с **вашим собственным** скрытым GitHub Gist. Пользователи полностью изолированы друг от друга.

## Возможности

- **PWA и полноценный офлайн-режим** — приложение можно установить на домашний экран телефона или ПК (как нативное приложение без браузерной строки). Все файлы, иконки и локальный шрифт кэшируются Service Worker (`sw.js`), поэтому можно просматривать, добавлять, редактировать и отмечать покупки полностью без интернета.
- **Сводный режим «ВСЕ» (`⊞`) и симметричная панель вкладок** — слева от списка вкладок закреплена компактная кнопка с общим счётчиком позиций, открывающая единый список товаров сразу по всем вкладкам с бейджами `ВКЛАДКА · КАТЕГОРИЯ`, глобальной сортировкой, всеми фильтрами и общими итогами без двойного счёта кредитов. Центральная полоса вкладок плавно прокручивается (стрелки `‹`/`›`, перетаскивание мышкой и колёсико на ПК), а справа закреплён менеджер вкладок (`•••` — сортировка `↑`/`↓` и drag-and-drop).
- **Категории, порядок и защита от дублей** — сворачивание любой категории кликом по всей её шапке, кнопка массового сворачивания/разворачивания (`−` / `+`), перенос/копирование категорий и карточек между вкладками, менеджер категорий (`•••`) и защита от создания одноимённых вкладок или дублирующихся категорий внутри одной вкладки.
- **Компактные карточки, сортировка и фильтры** — 5 уровней приоритета (`КРИТИЧНО`, `ОЧЕНЬ ВАЖНО`, `СРЕДНЕ`, `ЖЕЛАТЕЛЬНО`, `МОЖНО ОБОЙТИСЬ`), выбор магазина (настраиваемый список + свой вариант), кликабельный бейдж-ссылка магазина (`↗`), 5 режимов сортировки (`По приоритету`, `Сначала дорогие`, `Сначала дешёвые`, `Сначала новые`, `По алфавиту`) и фильтры по статусу, приоритету и магазину.
- **Глобальный Spotlight-поиск (`🔍 Поиск` / `Ctrl + K` на любой раскладке / `/`)** — умный многословный поиск сразу по всем вкладкам (включая архив), категориям, магазинам, названиям кредитов и всем строкам характеристик в заметках с подсветкой совпавшей строки, 4 быстрыми чипами-фильтрами (`Не куплено`, `Куплено`, `В кредите`, `Наличные`), навигацией стрелками `↑`/`↓` + `Enter` и мгновенным переходом к карточке.
- **Выдвижная панель карточки + фото-галерея** — открывается справа на ПК и шторкой снизу на мобилке. Поддерживает до 3 фото товара по URL (динамическое добавление полей `1 → 2 → 3`, галерея со стрелками/точками, полноэкранный зум Lightbox и тихое скрытие битых ссылок), а строки в заметке формата `Ключ: Значение` автоматически раскладываются в аккуратную таблицу характеристик.
- **Удобный ввод без потерь** — создание новой категории прямо из окна позиции (`+ Новая категория...`), автосохранение черновика, кнопка «Очистить», защита от случайного закрытия несохранённой формы и авторасширение поля заметки под текст.
- **Единый учёт кредитов, рассрочек и карты (кнопка «Кредиты» в шапке):**
  - Встроенные типы оплаты в долг (**`Рассрочка`** 0%, **`Ninja`** с %, **`Льготный период`** с датой возврата и счётчиком дней), пользовательские помесячные типы из Настроек и **`Свой вариант`**.
  - Оформление как на 1 товар, так и на **пачку товаров из разных вкладок** (в итоги каждой вкладки идёт её честная пропорциональная доля без двойного счёта). В окне выбора товаров уже оформленные в другие кредиты позиции скрыты по умолчанию, есть поиск и сворачивание вкладок.
  - Ручной ввод реального ежемесячного платежа и итоговой суммы под график банка; автоматический расчёт переплаты, даты окончания, оставшихся платежей и полоски прогресса.
  - Справочные поля **«Лимит карты»** (занято / свободно) и **«Доход / мес»** (процент кредитной нагрузки и остаток после платежей).
- **Двухвкладочное окно «Настройки» (`Общие` | `Синхронизация`):**
  - **Общие:** выбор валюты отображения (`₼`, `$`, `€`, `₽`, `₺`, `₸`, `₴`, `₾` или любой свой символ), управление списком **магазинов** (переименование, скрытие/показ глазиком, удаление своих и автодобавление при вводе нового в карточке) и **типов кредитов** (скрытие ненужных встроенных и добавление своих помесячных типов). Все предпочтения синхронизируются между устройствами через Gist.
  - **Синхронизация:** подключение Secret GitHub Gist, экспорт/импорт резервной копии `.json`, копирование JSON и полная очистка данных.
- **Светлая и тёмная темы + локальный шрифт** — тёмная тема по умолчанию (`#141414`), все цвета вынесены в `:root` в `css/tokens.css`, однострочная компактная шапка с иконками на мобильных экранах и локальный вариативный шрифт **Finlandica** (работает 100% офлайн).

## Как работает синхронизация и офлайн-автослияние (Secret GitHub Gist)

Синхронизация между ПК и телефоном работает напрямую через GitHub API без промежуточных серверов:

1. **Автоотправка (Auto-Push):** после любого изменения данные мгновенно сохраняются локально, а через **1.5 секунды** после последнего действия отправляются в скрытый Gist (`wm-checklist-data.json`).
2. **Бережная автоподгрузка (Auto-Pull):** при открытии страницы, возврате на вкладку (разблокировке телефона) и раз в **60 секунд** (только пока вкладка активна на экране) приложение проверяет обновления с заголовком `ETag` (`If-None-Match`). Если изменений нет, GitHub отвечает `304 Not Modified` и **не расходует лимит GitHub API** (0 из 5 000 запросов в час). Для крупных баз (> 1 МБ) предусмотрена автоматическая дозагрузка полного файла по `raw_url` (до 10 МБ).
3. **Умное офлайн-автослияние (Auto-Merge):** у каждой вкладки, категории, позиции и кредита хранится собственная метка `updatedAt` (плюс реестр удалённых ID). Если вы вносили правки на телефоне без интернета и одновременно добавляли товары на ПК, то при появлении сети приложение **автоматически объединит изменения с обоих устройств без потерь** (включая склейку параллельно созданных одноимённых категорий внутри одной вкладки) и отправит объединённую версию в Gist.

## Настройка синхронизации на своих устройствах

1. На GitHub откройте **Settings → Developer settings → Personal access tokens → Tokens (classic)** → **Generate new token (classic)**.
2. Укажите название (например, `wm-checklist`), срок действия и отметьте **только одно право — `gist`**.
3. Скопируйте полученный токен (`ghp_...`).
4. **На первом устройстве (ПК):** откройте https://whtmst.github.io/checklist/, нажмите **Настройки → Синхронизация**, вставьте токен → **Сохранить настройки** → **Отправить в GitHub ↑** (создастся скрытый Gist, его `Gist ID` пропишется автоматически).
5. **На втором устройстве (телефон):** откройте ту же ссылку, зайдите в **Настройки → Синхронизация**, вставьте тот же токен → **Найти мой Gist** → **Загрузить с GitHub ↓**.

> Токен сохраняется только в `localStorage` вашего браузера и никогда не попадает в код репозитория. При перевыпуске (Regenerate) токена данные в Gist не теряются — достаточно вставить новый токен в настройках.

## Структура проекта

```text
index.html        — разметка страницы, сводного режима «ВСЕ», Spotlight-поиска, панели просмотра и модалок
manifest.json     — манифест PWA для установки на телефон и ПК
sw.js             — Service Worker для кэширования и работы офлайн
assets/
  fonts/
    Finlandica-VariableFont_wght.ttf — локальный вариативный шрифт интерфейса
  icons/
    icon-192.png, icon-512.png       — иконки PWA (фон #141414 в тон сплэш-экрану)
css/
  tokens.css      — подключение шрифта и цветовые переменные (:root) для тёмной и светлой тем
  styles.css      — адаптивная вёрстка, галерея, Lightbox, Spotlight, вкладки Настроек и скроллбары
js/
  config.js       — справочники (приоритеты, пресеты валют, базовые магазины, типы долга) и расчёт сроков
  storage.js      — localStorage, CRUD, настройки справочников, сводный режим «ВСЕ», единый реестр кредитов и Auto-Merge
  sync.js         — синхронизация через Secret GitHub Gist (ETag / Auto-Pull / raw_url / офлайн-очередь) и JSON-бэкапы
  render.js       — безопасная DOM-отрисовка списка, режима «ВСЕ», Spotlight, панели просмотра, Настроек и кредитов
  app.js          — события, drag-and-drop, прокрутка вкладок, горячие клавиши, галерея/Lightbox, черновики, тема и PWA
```

## Запуск собственной копии на GitHub Pages

1. Сделайте форк или скопируйте файлы в корень своего репозитория.
2. Включите публикацию в **Settings → Pages → Build and deployment**:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` / `/ (root)` → **Save**.
3. Через 1–2 минуты приложение станет доступно по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
